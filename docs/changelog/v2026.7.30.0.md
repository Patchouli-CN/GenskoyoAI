# GensokyoAI v2026.7.30.0 更新日志

发布日期：2026-07-30

## 一句话总结

GensokyoWorld 多角色编排完整落地：从"演一个角色"升级到"单模型演一整台戏"——多个角色同处一个舞台，由导演按剧情决定每轮谁发言；控制台 `--world` 与 Runtime `world.*` RPC 全线可用。单角色模式行为零变化。

## 新增功能

- 新增 GensokyoWorld 多角色世界（默认关闭，`world.enabled` 或 `--world` 开启）。
  - 对用户的影响：多个角色可以同处一个舞台演戏。所有角色共享同一个模型（成本不翻倍），但各自拥有独立的会话、工作记忆与长期记忆；导演（Director）根据剧情、在场角色与戏剧时机决定 `continue` / `switch` / `wait_user`，不是轮流发言的群聊。
  - 是否需要操作：默认关闭，无需任何操作。想体验可参考 `config/world_example.yaml`（魔理沙 × 蕾米莉亚 × 红魔馆）一键开演：`uv run -m GensokyoAI.cli.main --config config/world_example.yaml`。
- 共享剧本（SharedTranscript）与舞台（WorldStage）：公开对话按场景分片记录，角色移动统一管理；`user_follows_current_actor` 开启时用户自动跟随当前演员换场景。
- 私有记忆投影：一段表演结束后，世界为每个在场角色各写一份"自己视角"的记忆（同一件事，魔理沙记的是得意，主人记的是有人擅闯）；不在场角色不会知道该场景发生的事。可用 `world.project_perspective_memories: false` 关闭。
- World 主循环主动剧情：整个世界只有一个主动定时器；段落结束后世界统一规划下一次剧情推进，到点由导演从当下在场角色中选角开口；用户发言永远优先并取消旧意图。单角色的主动定时器行为不变。
- 对话欲累积模型（`initiative_timer.drive_enabled`，默认关）：短期思考接入四维动机评估（表达欲/情感驱动力/关系需求/情景相关性），纯算术累积到阈值才主动开口，多轮不想说话零 token 成本；心情按非对称半衰期衰减，发言后泄压，状态随会话持久化。
- World 会话持久化与恢复：舞台、共享剧本、各角色私有会话独立存档（`world session schema v1`），`--resume` 或 `world.session.resume` 完整恢复；roster 差异经结构化诊断呈现，绝不静默串角色。
- 控制台 World 模式：`--world`（或 `world.enabled: true`）进入；动态发言者前缀（`魔理沙:` / `帕秋莉:`）、场景移动提示、主动剧情实时显示；新增 `/world`、`/roster`、`/stage`、`/transcript` 命令。
- Runtime `world.*` RPC（14 个方法）：`world.init` / `world.start` / `world.send_message` / `world.send_message_stream` / `world.state` / `world.roster` / `world.transcript` / `world.move` / `world.session.create` / `world.session.list` / `world.session.resume` / `world.session.delete` / `world.session.export` / `world.shutdown`。
  - 客户端影响：WebSocket `world.send_message_stream` 逐帧推送 `world.actor.started` / `world.actor.chunk` / `world.actor.completed` / `world.waiting_user` / `world.finish` 事件；`runtime.info` 新增 capability `world.orchestration`；事件订阅新增 `world` 分类（8 个 `world.*` 事件，已并入 `runtime_observable`）。
- 角色扮演系统提示框架新增第 6 条规则：提示词中的示例不再被模型当作角色性格参考，实际性格以角色卡为准（改善小模型把示例语气演成人格的问题）。

## 行为变化

- 强制主动发言兜底链已删除：`initiative_timer.fallback_on_no_schedule` 等 4 个配置键从 schema 移除——AI 决定不说话就是不说，不再强行安排"没话找话"。旧配置键会被静默丢弃并在配置校验时给出迁移警告（不报错）；主动定时器事件 payload 移除 `fallback_on_no_schedule` / `is_fallback` 字段，`source` 新增 `"drive"`。
- Runtime 事件敏感字段脱敏统一：全项目统一为 `sanitize_event_payload`，占位符统一为 `[REDACTED]`（此前 Runtime 事件出口使用 `[redacted]`）；脱敏字段集扩大到 `auth`、`passwd`、`headers`、`extra_headers` 及 `password` 子串匹配，方向更安全。
  - 客户端影响：若客户端曾精确匹配旧占位符 `[redacted]`，请改为 `[REDACTED]`。
- `dependency.install` 的 `timeout` 参数现在被钳制到 `resource_control.dependency_install_timeout_seconds` 配置上限；安装过程移到工作线程执行，不再冻结事件循环。
- 更高未知 schema version 的会话/记忆文件不再被静默降级改写版本号，与 World 存档的硬拒绝契约对齐为"不静默降级"（warning 后原样返回）。
- 兼容性：以上变化均不影响单角色模式的既有行为；旧会话、旧记忆、角色文件格式不变。

## 修复问题

- 修复 WebSocket 断连/取消落在发送窗口时幂等账本永久 `pending` 的问题：流式帧泵现在在 `finally` 中确定性关闭生成器，服务层将 `GeneratorExit` 收敛为 `cancelled`；此后同 `idempotency_key` 重试会收到明确的 `cancelled` 终态而非永久"仍在处理"。
  - 受影响场景：网络不稳定或客户端主动取消流式生成的远程部署。
- 修复 `handle_ws` 清理链可被心跳异常截断导致事件订阅/流任务泄漏的问题。
- 修复单租户 `operations.json` 损坏会拖垮整个进程启动的问题：租户目录现在按租户隔离加载，损坏只跳过该租户并记录 warning（不静默重建空账本）。
- 修复 `dependency.install` 在异步链路中同步执行 pip subprocess（最长 600 秒）冻结整个事件循环的问题。
- 修复响应代际竞态（孤儿生成）：请求代际绑定后，超时/取消的旧生成结果不再被投递。
- 修复 topics.json 崩溃即静默清空语义记忆的问题（原子替换 + 备份 + 损坏隔离）。

## 已废弃但仍兼容

- 无新增废弃。既有 legacy 非命名空间 RPC 方法（`init`、`send_message` 等）继续废弃保留，`remove_after` 仍为 `2.0.0`，替代方法见 `runtime.info.deprecated_methods`。

## 已移除或破坏性变化

- `initiative_timer.fallback_on_no_schedule` 等 4 个强制兜底配置键已移除（见"行为变化"）；旧键仅警告迁移，不阻断启动。
- Runtime 协议版本 `2.0.0` → `2.1.0`（major 仍为 `2`）：仅新增方法与能力，无删除、无字段语义变化，协议主版本不需要递增。

## 数据迁移与升级提醒

- 无数据迁移：会话 schema v2、记忆 schema v2、config schema v1 均未变化；World 存档为新增独立格式（`world session schema v1`），旧数据不受影响。
- 旧的 `initiative_timer.fallback_*` 配置键由 loader 静默丢弃，`config.validate` 会给出 `DEPRECATED_FIELDS` 迁移警告，按提示删除即可。

## 安装与依赖变化

- 无依赖变化：Python 3.14+ 与现有依赖集合不变，无需重新安装。

- 支持的客户端：兼容协议 major `2` 的客户端无需修改即可继续工作；`world.*` 为纯增量能力。
- methods 变化：新增 `world.init`、`world.start`、`world.send_message`、`world.send_message_stream`、`world.state`、`world.roster`、`world.transcript`、`world.move`、`world.session.create`、`world.session.list`、`world.session.resume`、`world.session.delete`、`world.session.export`、`world.shutdown`。

- 废弃 methods / fields：无新增。
- compatibility notes：无新增。
- breaking changes：无新增（协议 major 保持 `2`）。

## 已知问题

- WorkingMemory 目前不主动裁剪（`max_turns` 配置暂未生效），超长会话的上下文 token 会持续上涨；后续版本将按"记忆两层化"方向处理（短期工作记忆裁剪 + 长期语义记忆接管）。
- episodic 压缩子系统当前未启用（默认配置不受影响）。

## 面向开发者的补充说明

- 代码层变化：新增 `GensokyoAI/world/` 包（stage/transcript/director/persistence/memory_projector/initiative/world 主类）、`core/dialogue_loop.py` 与 `core/initiative_scheduler.py`（单角色/多角色共享的对话主循环抽象）、`core/agent/drive_accumulator.py`（对话欲累积）；`RuntimeState` 新增 `world` 字段（与 `agent` 互斥）；console 新增 `backends/console/world_backend.py`。
- 架构原则：单角色永不为多角色机制付费；对话真相源仍在 `Agent`，World 是其上的增量编排层；多个 Agent 绝不共享 EventBus，共享的只有 ModelClient 与资源闸门。
- 测试结果：`uv run pytest -q` 全量 609 passed（含 world 各层定向测试）；`uv run ruff check .`、`uv run pyright` 全绿。
- 文档更新：[`runtime_api.md`](../runtime_api.md) 新增 World 多角色编排 API 章节；README 中英、[`QUICKSTART.md`](../../QUICKSTART.md) 新增多角色章节。
- 发布前检查：[`versioning.md`](../versioning.md) 清单已核对——package 版本、协议版本、changelog、schema 表格一致。
